## 📱 Descrição

**CNPJ Brasil** é um aplicativo mobile construído com **Flutter** e **Dart**, que permite consultar dados de empresas por meio do seu número de **CNPJ**, utilizando a [BrasilAPI](https://brasilapi.com.br/). O projeto tem como objetivo demonstrar integração com APIs REST, manipulação de dados e desenvolvimento de UI responsiva.

---

## ✨ Funcionalidades

✅ **Consulta de CNPJ**  
✅ **Exibição de dados completos da empresa**  
✅ **Validação de entrada do usuário**  
✅ **Consumo de API em tempo real**  
✅ **Interface responsiva e amigável**
